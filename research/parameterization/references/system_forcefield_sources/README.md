# External Amber force-field sources

Complete installed Amber DAT/leaprc files are external runtime inputs, not
bundled here. source_manifest.json records the exact versions/hashes used for
this candidate generation. Provide matching gaff.dat, gaff2.dat, parm99.dat
and frcmod.ff99SB in this directory to reproduce generation. Generated
candidate subsets and line-level provenance are versioned under parameters/.
