# Charge comparison protocol

These comparisons assess transferable **charge controls** on identical finite fragments. They do not constitute fitted GO parameters, an MD force-field ranking, or a substitute for testing bonded, Lennard-Jones, mixing and 1–4 conventions together. No new QM ESP or RESP result is present in the baseline reports.

Run the baseline export from the project folder:

```sh
PYTHONPATH=src uv run python -m go_param.compare
```

`reports/reference_charge_summary.json` retains model atom IDs, individual assigned charges and provenance, unsupported atom IDs/roles, covered partial sum, complete sum where available, and error from formal charge. Its `role_charges` table and `reference_charge_summary.roles.csv` give the actual numerical role parameters and literature URLs. `reference_charge_summary.csv` summarizes model coverage and charge checks. A blank CSV charge or JSON null means unavailable, never zero.

## Sources and scope

- `current_gaff2`: user's archived GAFF2 block library charges, not generic GAFF2 default charges or a newly derived RESP model. GRT gives edge C/H −0.15/+0.15 e and GGG gives scaffold C 0 e. Functional roles override their secondary edge/scaffold annotations. CBX includes the carboxyl anchor charge −0.115 e; CBD includes the carboxylate anchor −0.18 e. Source atom names and local library paths are retained; no public URL is invented for local files.
- `hiergo_opls`: the 17 archived [HierGO charge rows](https://github.com/IFM-molecular-simulation-group/HierGO), commit and DOI in `references/reference_catalog.json`. Its own terminal C/H cap is −0.115/+0.115 e. Ether rows are retained in the role table although this fragment catalog has no ether model. No COO− charge set is present. This is a role-based charge control, not a reproduction of the complete HierGO graph typer or force field.
- `gopy_raw`: original [GOPY libraries](https://github.com/Iourarum/GOPY), including original zero epoxy and hydroxyl carbon charges. Current GRT supplies finite CH caps; the result is explicitly a **hybrid control**. Raw epoxy has sum −0.3691 e, hydroxyl −0.2271 e and COOH −0.0907 e. These are retained, not silently neutralized. GOPY lacks carbonyl and COO− coverage here. GGG scaffold zero is taken from GOPY itself.
- `stauffer_esp` / `stauffer_sesp`: only the published basal OH/epoxy entries of [Stauffer et al., Table I](https://orubel.mcmaster.ca/publications/2014/Stauffer_JCP_141_044705.pdf), DOI 10.1063/1.4890503. The archived table came from indexed primary text; the full PDF download was unavailable. Finite edge and scaffold charges are unsupported in these pure partial controls. `stauffer_esp_hybrid` / `stauffer_sesp_hybrid` add current GRT caps and GGG scaffold zero, labeled **hybrid controls**, never full published models. SESP is not RESP; the table's RESP column supplies no GO values.
- `old_whole_sheet`: separate descriptive reference only. Its original whole-sheet charges have no exact mapping to these new fragments. No averaging or renormalization is permitted.
- `pinto_gaff2_aim`: separate descriptive reference only. The [published source sheets](https://github.com/arvpinto/GO_sheets) use context-specific DDEC6 charge classes and AIM-volume LJ parameters with GAFF2 bonded terms. A mean charge transferred onto finite caps would not reproduce this published periodic model. All fragment atoms therefore remain unsupported.

## Matched ESP scoring after actual QM results exist

The callable `compare_esp(model, esp_ref, candidates)` accepts a model JSON path or record, a reference path or record, and candidate names or atom-resolved charge records. No ESP result is generated by baseline export. A reference must explicitly supply:

```json
{
  "atom_ids": [1, 2],
  "atom_positions_angstrom": [[0, 0, 0], [1, 0, 0]],
  "formal_charge": 0,
  "points_angstrom": [[0, 0, 2]],
  "potential_au": [0.0],
  "dipole_origin_angstrom": [0, 0, 0]
}
```

This is a schema illustration, not scientific reference data. The actual reference must include all model atoms in preserved order and the exact evaluated geometry. Charge fitting and comparison must use the same geometry, atom identity, formal charge, grid protocol and potential units. Geometry mismatches greater than 10⁻⁸ Å are rejected; no alignment or remapping is performed. The supplied origin is retained for dipoles, since the dipole of a charged system depends on origin. Charge-only candidate records identify each atom with `atom_id` and `charge_e` and declare `candidate` and `coverage` metadata; all charges are revalidated rather than trusting eligibility metadata.

Scoring calculates point-charge Coulomb potential in atomic units using Å-to-bohr conversion. Grid and atom dimensions are both chunked, bounding the pair arrays by `chunk_size²` (default 1024²). It reports RMSE, MAE, signed bias, maximum absolute error, relative RMSE against reference RMS (null if the reference RMS is zero), and dipole in e Å about the declared origin. No potential offset is fitted. All input arrays and assigned charges must be finite; grid/atom intersections are rejected.

Incomplete coverage is always skipped. Complete assignments must match formal charge within 10⁻⁶ e for primary matched-charge comparison. The optional `allow_charge_mismatch_diagnostic=True` enables a separately labeled `diagnostic_charge_mismatch` result for complete raw-charge controls, without correcting their charges. Such results must be excluded from the primary ranking. “Primary eligible” only records coverage and total-charge eligibility; it does not establish accuracy, validity of chemical transfer or full force-field compatibility.

Future RESP fits must carry original atom IDs and source/geometry provenance, pass the same checks, and be compared against these controls only after the actual QM outputs have been parsed and validated. Statistical or mechanistic conclusions require the planned independent geometries/fragments and downstream validation, not the existence of these baseline charge tables.
