# GO force-field candidates and portability

This catalog separates electrostatics from bonded terms, Lennard–Jones (LJ) parameters, combination rules, and 1–4 scaling. A force-field name alone is insufficient to reproduce a GO model. Values below are reference data, not evidence that a new fit is more accurate. Source files are preserved under `references/`; SHA-256 hashes and retrieval status are in `source_manifest.json`.

## Source values and immediate checks

`references/library_charges.json` records charges per library unit, including multiple units in one file. The raw GOPY E1A motif totals −0.3691 e, H1A totals −0.2271 e, C1A totals −0.0907 e, and GGG is zero. Their carbon charges were set to zero in the uploaded library. These are raw source sums, not formal molecular charges; adding counterions or rescaling the entire assembled sheet does not demonstrate chemically correct redistribution. The current `*_amber.lib` branch reproduces several of these values and must not be treated as identical to the current GAFF2 branch. `EPH_gaff2.lib` contains both EPH and EHH units; the extractor preserves them separately.

Stauffer Table I (charges in e): ESP epoxy O −0.24 and each C +0.12; hydroxyl O −0.38, C +0.12, H +0.26. SESP epoxy O −0.36 and each C +0.18; hydroxyl O −0.57, C +0.18, H +0.39. The modified AM1-BCC hydroxyl values are O −0.58, C +0.16, H +0.42. There are no GO entries in that table's RESP column. The author-hosted PDF's indexed text was readable, but direct PDF download timed out; this limitation is recorded in the extracted JSON. [Primary author copy](https://orubel.mcmaster.ca/publications/2014/Stauffer_JCP_141_044705.pdf).

`references/hiergo_17_charge_rows.json` preserves all source charge rows, including the same OPLS identifier used with different environment-specific charges. Representative neutral motifs: hydroxyl O −0.683/H +0.418/C +0.265, epoxide O −0.400/two C +0.200, carbonyl O −0.470/C +0.470. Mapping must use the environment/atom-name role as well as the OPLS type. [Pinned HierGO source](https://github.com/IFM-molecular-simulation-group/HierGO/tree/60382a1a1807ef0003ffcc3903392e913b1e5e9a).

`references/gaff2_aim_source_parameters.json` records source-specific LJ and charge values by actual type. The retrieved 15,597-atom sheet has O/C = 0.555621; the 12,819-atom sheet has O/C = 0.333372. Their summed charges are within 6 × 10⁻⁹ e of zero. These counts include H; neither atom count should be described as the number of carbon atoms. The source `atomtypes` charge column is zero; actual charges are in `[atoms]`. Do not infer neutrality from the former.

Pinto Supporting Information is locally available with publisher metadata. It specifies PBE/DZVP-MOLOPT-SR-GTH, DDEC6/Chargemol, volume-based LJ terms, and local-neighbor classes. Table S1 gives hydroxyl/epoxide composition. Table S14 is a small-system vacuum/water sensitivity table, not a generic transferable charge library; its printed σ unit is inconsistent with a length. Source topology σ is in nm and ε in kJ/mol. The SI PDF and its text are retained so this ambiguity remains auditable. [Publisher SI metadata](https://api.figshare.com/v2/articles/21395006).

## Comparison and fitting boundaries

Use identical molecular graphs, protonation, O/C, functional-group counts, water/ion model and sampling for controlled comparisons. Keep two experiments distinct: (1) charge-only sensitivity on the same bonded/LJ model; (2) each full published force field with its own LJ, mixing and 1–4 conventions. Mixed-charge/GAFF2 controls must be labeled hybrids. A larger dipole or more favorable adsorption energy is not by itself improved accuracy.

Directly portable artifacts are complete original topologies with their matching coordinates, and explicitly mapped local source parameters whose complete interaction conventions are retained. A new transferable modular charge model needs a documented fragment/motif set, exact QM/ESP settings, charge/equivalence constraints, treatment of boundaries and remote carbon, and held-out validation against ESP, dipoles and interaction energies. Condensed-phase validation should then test water organization and adsorption observables. Basal-plane DDEC6 types do not support unparameterized carboxylate, carbonyl, holes or finite edges automatically. No superiority claim is supported before these comparisons are computed.
